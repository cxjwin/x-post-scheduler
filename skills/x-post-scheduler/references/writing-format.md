# X 写作格式规范（反 AI 味收敛层，全 skill 共用）

适用范围：本套 skill 产出的一切给人读的文本——短推、线程、长文 Article、读后感。
这一层只管**格式**：标点、排版配额、结构套路。语气与人设由各 SKILL.md 的人设段落负责；
本规范的目标是把 AI 整理文本的典型痕迹主动收敛掉，别让格式出卖你。

原则一句话：**格式越少，人味越高。**判断、情绪和信息密度靠文字本身，不靠排版装饰。
（经验依据：同一作者的文章里，人味评价最高的几篇恰恰是小标题、加粗、破折号最少的；
格式最重的篇目全是 AI 整理稿。）

## 标点铁律

- 感叹号：正文零。兴奋靠砍短句子表达，不靠符号
- emoji：零。唯一例外是当数据标签用（✅ 自查清单、🟢🟡🔴 分档），不做语气装饰
- 破折号：默认不用，用逗号或句号替代；确需「补一刀」时全篇 ≤2 处（AI 整理稿的典型指纹是破折号 20+）
- 省略号：几乎不用
- 冒号：只做引出装置（引原话、引清单、引结论、引心里话），不写正文里「X：Y」式的名词解释句
- 引号：中文语境用直角引号「」，不用弯引号 ""
- 全角标点统一，不混半角逗号句号
- 数字与英文用半角，中英文之间留空格（「省了 2 小时」「Node 18 起步」）
- 中英混排不加注释：leader、token、HC 这类圈内词直接用，不写「领导者（leader）」注释体

## 排版配额

- **小标题**：默认不用，靠段落和转场句推进；确需分节时用带判断或悬念的口语短句（「第三个坑：模型开始说胡话」），禁止名词标签（「准备工作」「功能介绍」这种是 release note）
- **加粗**：全篇 ≤3 处，只给能独立成推的命题句；禁止术语高亮、禁止满屏划重点（加粗 30+ 是 AI 整理痕迹）
- **bullet 列表**：观点不用 bullet 罗列，改散文叙述；清单只用于真清单（步骤、自查、TODO），且每条带人称或具体物证、长短不齐；禁止正反例对称穷举（各 5-7 条无一句评价）、禁止「如果你是 X/Y/Z」三角色九宫格
- **一句成段**：是重音不是默认排版，每千字 ≤3 处，留给情绪峰值和核心判断；连排的一句一段 = 金句流水线
- **表格**：慎用——X 不渲染表格（本套 skill 会把它转成图或列表），能用两三句散文说清的不用表

## 禁用词

替换类：

- 「说白了」→「说穿了」「其实就是」
- 「本质上」→「说到底」，或直接删
- 「这意味着」→「翻译一下」「那结果是」
- 「换句话说」→「也就是说」「你想想看」

直接禁用：不可否认 / 综上所述 / 总的来说 / 值得注意的是 / 不难发现 / 首先…其次…最后 / 让我们

通稿词禁用：令人震惊 / 不可思议 / 赋能 / 颠覆 / 重磅 / 王炸 / 炸裂 / 历史性时刻 / 格局变了

## 结构性 AI 味（中一条改一条）

- 品牌/产品罗列 briefing 段：「C 端有…开发者端有…B 端有…」加括号注释，整段没有一个「我」
- 无人称顿号长清单：一句塞 6-10 个并列项，还连续多段
- 数据段连续三句以上无人话——每三句要插一句人话或比喻
- 万能总结句：「会出现非常多变体」「每个团队都不一样」——给不出具体差异就删掉
- 教科书开头：「在当今 AI 快速发展的时代」
- 「现在好转了」式假大空收尾——没好转就如实写没好转
- 三句同构的排比免责声明——免责要带人味，一句就够
- 假编第一人称场景（「比如有一次…」式虚构）——没有真实细节就退回写认知，或明说是转述

## 发布前机械扫描（L1 清单）

1. 搜禁用词与通稿词，命中即替换
2. 数标点：感叹号 0、emoji 0、破折号 ≤2、弯引号 0
3. 数配额：加粗 ≤3 且全是命题句、观点性 bullet 0、一句成段每千字 ≤3
4. 小标题逐个过：是否口语判断句，有没有名词标签混进来
5. 扫中英文空格、全角标点统一、数字半角

这五步全是机械检查，不需要判断力，写完必跑。语气、证据链、人设一致性等主观项归各 SKILL.md 自己的规则管。
